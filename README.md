# StoryStream Web App

## About the Project
StoryStream is a Java-based web application designed to help users explore books based on different age groups.

## Features
- Browse children's books
- Explore books for teenagers
- Browse books for elders
- Explore author-related books
- Search for books
- User login and registration

## Technologies Used
- Java
- JSP (JavaServer Pages)
- HTML
- CSS
- JavaScript
- MySQL (if configured in the project)
- Apache Tomcat
- Maven

## How to Run
1. Clone or download this repository.
2. Import the project into Eclipse as an existing Maven project.
3. Configure Apache Tomcat in Eclipse.
4. Configure the database connection if required.
5. Run the project on the server.
